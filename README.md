#  AI Library Chatbot - Book Search Assistant

This is a Python-based AI chatbot prototype that helps users search for books in a library system using natural language. It supports fuzzy title matching and author-based searches, and includes a simple web-based interface.

##  Features

-  Fuzzy Title Matching
-  Author Name Search
-  Graceful Error Handling
-  Web Interface
-  CORS-Enabled for browser support

##  Technologies Used

- Python 3.x, Flask, flask-cors
- HTML + JavaScript
- difflib for fuzzy matching

##  How to Run the Chatbot

1. Install requirements:
   ```
   pip install flask flask-cors
   ```

2. Run the server:
   ```
   python app.py
   ```

3. Open `chat.html` in your browser and type:
   - `river source`
   - `books by Chinua Achebe`
   - `Harry Potter`

##  Purpose

A demo for AI use in Kenyan library systems — part of a Business and Information Automation project.
